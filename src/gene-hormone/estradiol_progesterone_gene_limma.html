Limma-voom association of estradiol and progesterone with pseudobulk gene expression. Sex-combined analysis with sex as covariate (celltype-level). Tests base (~ hormone + Sex) and GW-adjusted (~ hormone + GW + Sex) models.

Inputs data/cache/pb_base.rds, doc/targeted/targeted_hormones.xlsx
Outputs Result CSVs and figures in results/gene-hormone/estradiol_genes/ and results/gene-hormone/progesterone_genes/
Upstream prep_data.R
Downstream targeted_gene_list_limma.qmd

Goals

Identify genes whose pseudobulk expression is predicted by estradiol (E2) and progesterone (P4) concentration, by cell type. Both hormones are analyzed sex-combined: XX and XY samples are pooled, with Sex optionally included as an additive covariate.

Four models tested per hormone:

  • Base — ~ hormone
  • Base + Sex — ~ hormone + Sex
  • Base + Batch — ~ hormone + batch1_frac
  • Base + Sex + Batch — ~ hormone + Sex + batch1_frac

All four models use analyze_hormone_combined(). Samples from both sexes contribute to each cell type estimate regardless of whether Sex enters the formula.

Gene filter: manual rowSums — genes with ≥ 2 counts in ≥ 3 samples per cell type.
Sample threshold: floor(n_group / 2) non-zero hormone samples required per cell type.

Outlier Removal

Samples with hormone > Q3 + 1.5 × IQR are excluded per hormone before pseudobulk construction.

detect_outliers <- function(data, variable) {
  outlier_limit <- quantile(data[[variable]], 0.75, na.rm = TRUE) +
    1.5 * IQR(data[[variable]], na.rm = TRUE)
  data %>% dplyr::filter(.data[[variable]] <= outlier_limit)
}

Models

Model Formula Notes
Base ~ hormone Combined-sample estimate; no adjustment
Base + Sex ~ hormone + Sex Controls for sex-linked expression differences
Base + Batch ~ hormone + batch1_frac Batch1 fraction per sample (continuous); absorbs residual batch composition differences
Base + Sex + Batch ~ hormone + Sex + batch1_frac Both adjustments
