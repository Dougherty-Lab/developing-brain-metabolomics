Estradiol and progesterone–gene limma-voom at the class-level annotation.

Inputs data/cache/pb_base_class.rds, doc/targeted/targeted_hormones.xlsx
Outputs results/gene-hormone/estradiol_genes_class/, results/gene-hormone/progesterone_genes_class/
Upstream prep_data.R
Downstream None

Goals

Identify genes whose pseudobulk expression is predicted by estradiol (E2) and progesterone (P4) concentration, by class. Both hormones are analyzed sex-combined: XX and XY samples are pooled, with Sex optionally included as an additive covariate.

Four models tested per hormone:

  • Base — ~ hormone
  • Base + Sex — ~ hormone + Sex
  • Base + Batch — ~ hormone + batch1_frac
  • Base + Sex + Batch — ~ hormone + Sex + batch1_frac

Drops groups where fewer than 2 sexes are present after hormone filtering, applies to every model.

Gene filter: manual rowSums — genes with ≥ 2 counts in ≥ 3 samples per class.
Sample threshold: floor(n_group / 2) non-zero hormone samples required per class.

Outlier Removal

Samples with hormone > Q3 + 1.5 × IQR are excluded per hormone before pseudobulk construction.

detect_outliers <- function(data, variable) {
  outlier_limit <- quantile(data[[variable]], 0.75, na.rm = TRUE) +
    1.5 * IQR(data[[variable]], na.rm = TRUE)
  data %>% dplyr::filter(.data[[variable]] <= outlier_limit)
}

targeted_comparison_filtered_E2 <- detect_outliers(targeted_comparison_raw, "E2")

Models

Model Formula Notes
Base ~ hormone Combined-sample estimate; no adjustment
Base + Sex ~ hormone + Sex Controls for sex-linked expression differences
Base + Batch ~ hormone + batch1_frac Batch1 fraction per sample (continuous); absorbs residual batch composition differences
Base + Sex + Batch ~ hormone + Sex + batch1_frac Both adjustments
